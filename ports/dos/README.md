# DOS port

This is the original SNAKE! release from 2003. It contains the historical
assembly source and the built DOS executable:

- `snake-source.asm` — original source, including the `_Faster` 2003 credit
- `snake.exe` — the original executable

Run `snake.exe` with [DOSBox](https://www.dosbox.com/) or compatible DOS
software. The source is kept as-is as a historical artifact rather than being
modernized into a different dialect.
